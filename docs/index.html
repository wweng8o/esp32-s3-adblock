🛡️ esp32-s3-adblock

A Pi-hole-style DNS ad-blocker for the ESP32-S3 that blocks 2.3 million domains from 11.5 MB of flash — no server, no SD card, no domain strings in RAM.

2.3Mblocked domains

Based on M-Abozaid/esp32-c3-adblock — "Pi-hole-class DNS ad-blocker on a $2 ESP32-C3 (no PSRAM): 537k domains as 40-bit FNV-1a hashes, flash binary search." This fork is ESP32-S3 only and grows the list to 2.3M. Upstream demo.

How it works

Domains are stored as sorted 40-bit FNV-1a hashes. A query is hashed (plus each parent suffix) and binary-searched. A hit is answered 0.0.0.0; anything else is forwarded to your resolver asynchronously, so one slow lookup never stalls the rest of the network.

query in ──▶ extract domain ──▶ FNV-1a hash (+ parent suffixes)
         ──▶ binary search the sorted hash table
              ├─ hit  ──▶ 0.0.0.0        (sinkholed)
              └─ miss ──▶ upstream (async), relay reply

Lists up to ~1.5M domains are mirrored into PSRAM at boot, turning lookups into in-RAM binary searches. The 2.3M preset exceeds 8 MB of PSRAM and uses the flash index instead.

Flash it

  1. Grab esp32s3-n16r8-firmware.bin, s3-bootloader.bin, s3-partitions.bin and boot_app0.bin from the releases page.
  2. Flash them at 0x0, 0x8000, 0xe000 and 0x10000.
  3. Join the S3-AdBlock-XXXX access point, pick your WiFi, done.
  4. Point your router's DNS at the board and open http://s3adblock.local.
