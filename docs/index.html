🛡️ esp32-s3-adblock

A Pi-hole-style DNS ad-blocker that runs on an ESP32-S3 and blocks 2.3 million domains from 11.5 MB of flash — no server, no SD card, no domain strings in RAM.

2.3Mblocked domains
11.5 MBflash, not RAM
~10 msper blocked lookup
113 KBfirmware RAM

How it works

Domains are stored as sorted 40-bit FNV-1a hashes. A query is hashed (plus each parent suffix) and binary-searched. A hit is answered 0.0.0.0; anything else is forwarded to your resolver asynchronously, so one slow lookup never stalls the rest of the network.

query in ──▶ extract domain ──▶ FNV-1a hash (+ parent suffixes)
         ──▶ binary search the sorted hash table
              ├─ hit  ──▶ 0.0.0.0        (sinkholed)
              └─ miss ──▶ upstream (async), relay reply

On lists that fit in PSRAM (up to ~1.5M domains) the table is mirrored into PSRAM at boot, turning lookups into in-RAM binary searches.

Flash it

  1. Grab firmware.bin and littlefs.bin from the releases page.
  2. Flash both with esptool or PlatformIO (see the README for exact offsets).
  3. Join the C3-AdBlock-XXXX access point, pick your WiFi, done.
  4. Point your router's DNS at the board and open http://c3adblock.local.
